## Design Specificity Verdict
Content layer authored for the product (protected, newcomer grace, diagnosis, rule arithmetic, cost before scan). Chrome is interchangeable tactical-dark-ops (eyebrows, Control room, fake Infrastructure block, orbit animation, invented hex mark). Structural gap: no low-activity report page while tracked posts get a whole route.

## Priority Issues
- [P0] Low-activity report has no page; the Members "Low Activity" filter applies only the threshold, not protection/newcomer exclusions. Fix: dedicated report that applies the rules and states them, with CSV. (/impeccable shape, /impeccable layout)
- [P1] Toasts render behind dialogs (styles.css: .toast z-index 80 vs .modal-backdrop 100). (/impeccable harden)
- [P1] Scoring explanation text is the least legible on screen (--muted-2, ~10px, ~3.3:1). (/impeccable typeset)
- [P1] Save & rescore: no confirm, no diff, no dirty state; 21 placeholder descriptions; Scan guardrails mixes policy with API caps. (/impeccable clarify)
- [P2] Ritual has no thread; Reset misplaced under Scoring; no "This cycle" panel. (/impeccable shape)
- [P2] Member drawer overload: edit + points + deep scan + 100 rows at once, three primaries. (/impeccable distill)
- [P3] Generic chrome: Infrastructure block, eyebrows, filler captions, number locale. (/impeccable quieter)
